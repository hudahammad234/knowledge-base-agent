# AI Knowledge Assistant - Export & Evaluation

This project contains export and evaluation modules for an AI Knowledge Assistant.

## Features
- Export conversations into Markdown and TXT files.
- Store user questions, assistant answers, and document sources.
- Evaluate AI responses using predefined test questions.
- Measure retrieval accuracy, answer grounding, and confidence score.
- Detect unsupported answers and reduce hallucination.
- Generate an automatic evaluation report in Markdown format.

## Workflow
The system rewrites user queries, retrieves relevant document chunks, generates answers, validates responses, stores conversation memory, and produces evaluation results.

## Output
Generated files include conversation exports and `evaluation_report.md` containing evaluation scores and detailed results.

## Purpose
This module helps monitor AI assistant performance, improve response quality, and ensure answers are based on the provided knowledge base.
